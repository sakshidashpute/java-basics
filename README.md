# Java Basics 

This repository contains basic Java programs for learning and practice.  
It is useful for beginners to understand core concepts of Java.

---

##  Topics Covered

- Variables and Data Types
- Operators
- Control Statements (if-else, switch)
- Loops (for, while)
- Functions / Methods
- Recursion
- Arrays
- Strings
- OOP Concepts (Class, Object, Inheritance, Polymorphism)

---

##  Programs Included

- Hello World Program
- Print Name Program
- Even or Odd Number
- Prime Number Check
- Fibonacci Series
- Factorial (Loop & Recursion)
- Reverse Number
- Palindrome Number
- Armstrong Number
- Pattern Programs
